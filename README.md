# Thus Spoke Zarathustra
A guided reading companion with an existing English book reader and a multilingual entry page.

## Languages
Open [languages.html](languages.html). English uses the existing local Thomas Common reader; German, French, Italian and Spanish link to external editions. Persian, Czech, Arabic, Turkish, Portuguese, Russian, Chinese and Japanese have short reading introductions, **not full book translations**.

Source URLs and language metadata: [editions.json](editions.json). Checked 2026-10-13.

## Contribute a language
1. Identify the exact edition and translator; provide a source URL and evidence of reuse permission.
2. Distinguish complete book text, a reading introduction, and an original interpretation.
3. Preserve attribution and edition-specific terms. Do not place modern translations under a blanket repository license.
4. Add the language to editions.json and languages.html; use lang attributes and dir=rtl where needed.
5. Check all four book parts, navigation, keyboard use and mobile layout before calling a translation complete.

The multilingual entry page links to external editions rather than copying or machine-translating the full book. It adds no tracking or third-party scripts.

## Expanded introductory languages
The short reading guide is now available in 13 languages. Arabic, Turkish, Portuguese, Russian, Chinese and Japanese were added on 2026-10-14. Their book links explicitly open the existing English reader; full book translations into these languages have not been added. Arabic and Persian use right-to-left layout. The introduction layer of the translation map includes all 13 languages; the chapter map still covers one discourse in five editions.
